# ☕ OKYNI – Página Web para Cafetería

Proyecto web desarrollado como práctica de **HTML y CSS**, enfocado en el diseño de una página para una cafetería llamada **OKYNI**.

## 📌 Descripción

La página fue creada con el objetivo de practicar el desarrollo de interfaces web modernas y mejorar mis habilidades en **maquetación, estilos y diseño responsivo básico**.

Incluye secciones informativas típicas de una cafetería, como presentación del negocio, productos y contenido visual atractivo para el usuario.

## 🛠️ Tecnologías utilizadas

* **HTML5**
* **CSS3**

## ✨ Características

* Diseño visual para una cafetería
* Estructura organizada con secciones semánticas
* Estilos personalizados con CSS
* Distribución de contenido e imágenes
* Navegación sencilla y fácil de usar

## 📂 Estructura del proyecto

```
📁 okyni
 ┣ 📄 index.html
 ┣ 📄 style.css

 ┗ 📄 README.md
```

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio:

```bash
git clone https://github.com/juaxmelo-dot/okyni.git
```

2. Abre la carpeta del proyecto.

3. Ejecuta el archivo **index.html** en tu navegador.

## 🎯 Objetivos de aprendizaje

Con este proyecto practiqué:

* Uso de **HTML semántico**
* Aplicación de **CSS para diseño visual**
* Organización de contenido en una página web
* Uso de colores, tipografías y espaciado
* Creación de una interfaz enfocada en una cafetería real

## 📚 Lo que aprendí

* Diseñar una landing page básica para un negocio
* Mejorar la presentación visual de un sitio web
* Organizar elementos utilizando contenedores y estilos CSS
* Crear una experiencia visual más agradable para el usuario
